# 🦁 Pine City Zoo Website

A responsive multi-page zoo website built using **HTML and CSS** as part of my web development learning journey.

## 📌 About the Project

The Pine City Zoo project is a front-end website designed to provide visitors with information about a fictional zoo, including its animals, attractions, facilities, and other important information.

The project focuses on developing fundamental **HTML and CSS** skills, including page structure, navigation, layouts, images, backgrounds, and fixed navigation elements.

## 🛠️ Technologies Used

* **HTML5** – Page structure and content
* **CSS3** – Styling, layouts, backgrounds, navigation and information boxes
* **Images** – Visual content and backgrounds

## ✨ Features

* 🏠 Home page
* 🦁 Animal information pages
* 🏞️ Zoo attraction information
* 📍 Location and map sections
* 📱 Navigation tabs
* 🎨 Custom backgrounds and styling
* 📦 Information boxes for displaying content
* 🔗 Navigation between different pages
